What these numbers mean

Acceptance means a row passed the implemented rules. It does not establish verified financial accuracy or detect fraud. Quarantined records are excluded from this streaming demo's ledger comparison.

How this relates to the GitHub project

The original Python/SQLite batch project checks 1,001 source rows, accepts 995, quarantines 6, and finds 8 two-sided reconciliation exceptions. This separate JavaScript demo generates a new streaming population, so its counts differ. It demonstrates source-driven reconciliation only; it does not simulate ledger-only records, production persistence, or external banking feeds.
